MongoDB’s createIndex() is used to create indexes on collection fields to improve query and sorting 
    performance, with support for multiple index types and customization options.

    - MongoDB avoids creating duplicate indexes with the same key pattern and options
    - Indexes can be hidden or unhidden using hideIndex() and unhideIndex().

    Syntax:
            db.collectionName.createIndex(
                { field_name: 1 },
                {
                    commitQuorum: <string or integer>
                }
            )

Examples: 
        1: Create an Ascending Index on a Single Field
            - db.student.createIndex({name:1})

        2: Create a Descending Index on a Single Field
            - db.student.createIndex({language:-1})

        3: Create an Index on the Multiple Fields
            - db.student.createIndex({name:1,language:-1})

        4: Creating a Unique Index Using Options:
            - db.student.createIndex({name: 1}, {unique: true})

        5: Creating a Wildcard Index
            - db.student.createIndex({"branch.$**":1})

        6: Create Indexes with Collation Specified
            - db.student.createIndex( { "name": 1 }, { collation: { locale: "en", strength: 2 } } )

        7: Create Index With Commit Quorum
            - db.student.createIndex( { "name": 1 }, { commitQuorum: "majority" } )
