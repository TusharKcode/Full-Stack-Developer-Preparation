Dropping a 'database' in MongoDB permanently deletes the database along with all its collections and documents, 
    helping maintain a clean database environment.

Reasons for Dropping a Database in MongoDB:
-> Data cleanup & Performance Optimization
-> Development and testing
-> Security and Compliance
-> Storage Management

Steps to Drop a Database in MongoDB:
-> show dbs
-> use sampleDB
-> db.dropDatabase()
-> show dbs (to verify)

Dropping a 'collection' in MongoDB permanently removes the collection along with all its documents and indexes, 
    helping maintain a clean and organized database.

    Syntax:     db.collection_name.drop({writeConcern: <document>})

    Example:    db.student.drop() // Output: true
