CRUD operations are fundamental database actions in MongoDB that enable users to insert, read, update, and 
    delete documents within collections.

1. Create Operations
    - Create (insert) operations are used to add new documents to a collection, creating the collection 
        automatically if it does not already exist.
    - Generates a unique _id if not provided.
    - Supports inserting single or multiple documents.

    -> db.createCollection() method.
    -> db.collection.insertOne() method.
    -> db.collection.insertMany() method.

2. Read Operations
    - Read operations are used to retrieve or query documents from a MongoDB collection.
    - Support filtering, projection, sorting, and limiting results.
    - Used to read and analyze stored data.

    -> db.collection.find() method.
    -> db.collection.findOne() method.

3. Update Operations
    - Update operations are used to modify existing documents in a MongoDB collection based on specified query 
        conditions.
    - Update single or multiple matching documents.
    - Use update operators like $set, $inc, and $unset.
    - Can replace entire documents if required.

    -> db.collection.updateOne() method.
    -> db.collection.updateMany() method.
    -> db.student.replaceOne() method.

4. Delete Operations
    - Delete operations are used to remove documents from a MongoDB collection.
    - Based on specific conditions.
    - Can remove a single document or multiple documents
    - Supports deleting all documents in a collection

    -> db.collection.deleteOne() method.
    -> db.collection.deleteMany() method. (empty filter {} is used)
