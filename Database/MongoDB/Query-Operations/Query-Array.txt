Efficient querying of array elements in MongoDB helps developers extract relevant data from flexible, 
    document-based collections.
    - Arrays store ordered, related values within a document.

Methods to Query Array Elements in MongoDB:
    1. Dot Notation
        - accesses fields inside nested objects or arrays in MongoDB queries.
        Query: db.blogPosts.find({ "comments.user": "Adam" })

    2. $elemMatch
        - matches documents where at least one array element satisfies multiple conditions.
        Query: db.blogPosts.find({ comments: { $elemMatch: { user: "Alen" } } })

    3. $slice
        - $slice limits the number of array elements returned in query results.
        Query: db.blogPosts.find({}, { title: 1, comments: { $slice: 1 } })

    4. $all
        - $all matches documents where an array contains all specified elements.
        Query: db.blogPosts.find({
                    comments: {
                        $all: [
                        { $elemMatch: { user: "Alexander" } },
                        { $elemMatch: { user: "Sophia" } }
                        ]
                    }
                })

    5. $in
        - $in matches documents where a field equals any value from a given list.
        Query: db.blogPosts.find({ comments: { $elemMatch: { user: { $in: ["Denial", "Tim"] } } } })

    6. $unwind
        - $unwind breaks an array into multiple documents in the aggregation pipeline.
        Query: db.blogPosts.aggregate([{ $unwind: "$comments" }])
