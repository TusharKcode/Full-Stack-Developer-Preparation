SQL provides the WHERE clause to filter rows based on one or more conditions. It ensures that queries return 
    or modify only the required records.
    - It is used with SELECT, UPDATE, and DELETE statements.
    - It works with comparison and logical operators.

    Syntax: SELECT column1, column2
            FROM table_name
            WHERE column_name operator value; 

    Examples:
        -> Where Clause with Logical Operators: SELECT * FROM Employees WHERE Age=24;

        -> WHERE with Comparison Operators:     SELECT EmpID, Name, Country FROM Employees WHERE Age > 21;

        -> Where Clause with BETWEEN Operator:  SELECT * FROM Employees WHERE Age BETWEEN 22 AND 24;

        -> Where Clause with LIKE Operator:     SELECT * FROM Employees WHERE Name LIKE 'L%';

        -> Where Clause with IN Operator:       SELECT Name FROM Employees WHERE Age IN (21,23);

    Operators:
        >	        Greater Than
        >=	        Greater than or Equal to
        <	        Less Than
        <=	        Less than or Equal to
        =	        Equal to
        <>	        Not Equal to
        BETWEEN	    In an inclusive Range
        LIKE	    Search for a pattern
        IN	        To specify multiple possible values for a column
