SQL commands are fundamental building blocks used to perform given operations on database. 
    - include queries of data
    - Creating a table, adding data to tables, dropping the table, modifying the table and setting 
        permissions for users

    Terms:
        - Database:         A collection of organized data.
        - Table:            Stores data in rows and columns.
        - Row (Record):     A single entry in a table.
        - Column (Field):   An attribute of the data.
        - Primary Key:      Uniquely identifies each record.
        - Query:            A request to access or modify data.
        - Constraint:       Rules applied to ensure valid data.
