SQL Date Functions are built-in tools used to handle, modify and analyze date/time values in a database. 
    - perform tasks like retrieving current dates, calculating differences and formatting results effectively.
    - Extract specific parts of a date (year, month, day).
    - Format dates for user-friendly display.
    - Track trends, deadlines or schedules in business processes.

    -> NOW()
        - retrieves the server’s current date and time
        - useful for capturing exact event moments such as transaction timestamps, as well as for logging 
            and comparing time-based records.
        - Returns the current system date and time.
        - Shows both date and time in one value.
        
        Syntax: SELECT NOW() AS current_datetime;

    -> CURTIME()
        - returns the current time in HH:MM:SS format
        - useful for time-based operations, such as scheduling or performing precise time comparisons.
        - Returns the current system time.
        - Shows hours, minutes and seconds only.

        Example:    SELECT CURTIME() AS current_time; 

    -> DATE()
        - extracts only the date from a date or datetime value
        - Removes any time portion if present.

        Example: SELECT sale_id, product_name,DATE(sale_date) AS sale_date_only FROM sales;

    -> EXTRACT()
        - retrieves a specific part of a date such as the year, month or day
        - useful for grouping, filtering or performing time-based analysis including year-over-year reports.

        Example: SELECT sale_id, product_name, EXTRACT(YEAR FROM sale_date) AS sale_year FROM sales;

    -> DATE_ADD()
        - adds a chosen time interval such as days, months or years to a date
        - useful for calculating future dates and simplifying planning or scheduling tasks.

        Example:    SELECT sale_id, product_name, DATE_ADD(sale_date, INTERVAL 7 DAY) AS sale_date_plus_7_days 
                    FROM sales;

    -> DATE_SUB()
        - subtracts a chosen time interval from a date
        - useful for determining past dates and performing retrospective data analysis.

        Example:    SELECT sale_id, product_name, DATE_SUB(sale_date, INTERVAL 3 DAY) AS sale_date_minus_3_days
                    FROM sales;

    -> DATEDIFF()
        - returns the number of days between two dates
        - useful for calculating durations such as deadlines or overdue periods

        Example:    SELECT sale_id, product_name, sale_date, DATEDIFF('2024-08-15', sale_date)
                    AS days_until_aug15 FROM sales;

    -> DATE_FORMAT()
        - formats a date using a specified pattern
        - allowing customized output such as full day or month names

        Example:    SELECT sale_id, product_name, DATE_FORMAT(sale_date, '%W, %M %d, %Y') 
                    AS formatted_sale_date FROM sales;

    -> ADDDATE()
        - adds a specified time interval to a date
        - useful for calculating future or past dates based on a given date.

        Example:    SELECT sale_id, product_name, ADDDATE(sale_date, 10) 
                    AS sale_date_plus_10_days FROM sales;

    -> ADDTIME()
        - adds a specified time interval to a time or datetime value. 
        - useful for adjusting times by adding hours, minutes or seconds.

        Example:    SELECT sale_id, product_name ADDTIME('10:30:00', '02:30:00') AS sale_time_plus_2hrs_30min
                    FROM sales;
