SQLite is lightweight, file-based, serverless, easy to set-up.
    - It is included with Python through 'sqlite3'

-> Connection
    # Create Python file,
                        database.py 
    # Then, 
            import sqlite3

            connection = sqlite3.connect(app.db)    - This establish a connection b/w Python program &
                                                        database
    # To execute SQL query, use Cursor

            cursor = connection.cursor()            - creates a cursor
            cursor.execute("""                      - executes SQL query
                CREATE TABLE IF NOT EXISTS user (
                    id INTEGER PRIMARY KEY AUTOINCREMENT,
                    name TEXT NOT NULL,
                    age INTEGER,
                    email TEXT UNIQUE NOT NULL
                )
            """)

    # Inserting data with Python

            cursor.execute("""
                INSERT INTO users (name, email, age)
                VALUES (?, ?, ?)                    - These are Parameterized values, helps protect 
            """, ("John", "john@example.com", 25))      against SQL Injection

    # To read data 

            cursor.execute("SELECT * FROM users")   
            users = cursor.fetchall()

            for user in users:
                print(user)                 - Each row is returned as a tuple by default

            print("Database connected!")
            connection.commit()             - save changes (need for INSERT, UPDATE, DELETE, to commit 
                                                transaction)
            connection.close()              - close the connection



-> fetchone() - to get 1 result (row)

    Ex: cursor.execute(
            "SELECT * FROM users WHERE id = ?",
            (1,)
        )
        user = cursor.fetchone()
        print(user)

-> fetchall() - to get all matching result (row)

    Ex: cursor.execute(
            "SELECT * FROM users WHERE age >= ?",
            (25,)
        )
        user = cursor.fetchall()

-> Update with Python
    Ex: cursor.execute(
            """
            UPDATE users
            SET age = ?
            WHERE id = ?
            """,
            (26, 1)
        )
        connection.commit()

-> Delete with Python
    Ex: cursor.execute(
            "DELETE FROM users WHERE id = ?",
            (2,))
        connection.commit()
