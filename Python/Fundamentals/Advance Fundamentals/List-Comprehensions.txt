List Comprehension is a compact way to create a new list from existing sequence or iterable.
    Useful in transforming data.

    Syntax: [expression for item in iterable]
        
            [What-to-put-in-list for each-item in source]
        
        # with condition
            [expression for item in iterable if condition]

        # if-else
            [expression_if_true if condition else expression_if_false for item in iterable]


    Ex: numbers = [1,2,3,4,5]
        doubled = [number * 2 for number in numbers]
        print(doubled)                  # [2, 4, 6, 8, 10]

        numbers = [10,25,30,13,11]
        greater_than_20 = [number for number in numbers if number > 20]
        print(greater_than_20)                  # [25, 30]

        skills = ["python", "fastapi", "react"]
        uppercase_skills = [skill.upper() for skill in skills]
        print(uppercase_skills)                 # ['PYTHON', 'FASTAPI', 'REACT']

        numbers = [number for number in range(1, 6)]
        print(numbers)

        numbers = [1, 2, 3, 4, 5]
        result = ["Even" if number % 2 == 0 else "Odd" for number in numbers]
        print(result)

        text = "Python Programming"
        vowels = [letter for letter in text.lower() if letter in "aeiou"]
        print(vowels)
