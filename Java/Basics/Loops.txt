Loops in programming are used to execute a block of code repeatedly until a specified condition is met.
    - reduce code duplication and make programs more efficient and readable.
    - essential for handling repetitive tasks.

Types: 
    => FOR loop:
        - used when we know the number of iterations
        - includes the initialization, condition, and increment/decrement in one line. 
        Syntax: for (initialization; condition; increment/decrement) {
                    // code to be executed
                }

    => FOR-EACH loop:
        - used to iterate over arrays or collections.
        Syntax: for (dataType variable : arrayOrCollection) {
                    // code to be executed
                }

    => WHILE loop:
        - used when we want to check the condition before executing the loop body.
        Syntax: while (condition) {
                    // code to be executed
                }

    => DO-WHILE loop:
        - ensures that the code block executes at least once before checking the condition.
        Syntax: do {
                    // code to be executed
                } while (condition);

Loops Mistakes: 
    -> Infinite loops - any sort of looping is that it may not ever exit, that is the loop runs for infinite
                        time.
    -> Off-by-One Errors - when the loop runs one more or one fewer time than you wanted, happens 
                            when the loop condition is not set correctly.

    -> Modifying Loop Variables Inside the Loop
    -> Empty Loop Body- when a loop is written to iterate but does not perform any operations inside the loop

"Jump Statements"
    - Used to change the normal execution flow of a program
    - Help in exiting loops, skipping iterations, or returning from methods

    -> Continue - pushes the next repetition of the loop to take place, skipping any code between 
                    itself and the conditional expression that controls the loop.
    -> Break - used to terminate the execution of the nearest looping statement or switch statement.
                used with the switch statement, for loop, while loop, and do-while loop. 
    -> Return - help you transfer control from one method to the method that called it
                "return" is a reserved keyword means we can’t use it as an identifier
                used to exit from a method, with or without a value

        Ex: public static int calculateSum(int num1, int num2){

                System.out.println("Calculating the sum of " + num1
                                + " and " + num2);

                System.out.println("The sum is: " + sum);

                // Return the calculated sum
                return sum;
