Java data types define the type of data a variable can store in a program.
    - They help the compiler allocate memory efficiently and ensure type safety.

    => Types of Data Types
        - Primitive Data Types: Store simple values directly in memory.
        - Non-Primitive (Reference) Data Types: Store memory references to objects.

"Primitive Data Type"
    -  Java provides eight primitive data types, each with a fixed size and range

    'boolean' -> Logical values           -> false  -> Not JVM-defined -> true, false	(true or false)
    'byte'    -> 8-bit signed integer     -> 0      -> 1 byte          -> 10	        (-128 to 127)
    'char'    -> 16-bit Unicode character -> \u0000 -> 2 bytes         -> 'A', '\u0041'	(0 to 65,535)
    'short'   -> 16-bit signed integer    -> 0      -> 2 bytes         -> 2000	        (-32,768 to 32,767)
    'int'     -> 32-bit signed integer	  -> 0      -> Not JVM-defined -> 1000, -500	(-2,147,483,648 to 
                                                                                            2,147,483,647)
    'long'    -> 64-bit signed integer    -> 0L     -> Not JVM-defined -> 123456789L	(±9.22e18)
    'float'   -> 32-bit floating point    -> 0.0f   -> Not JVM-defined -> 3.14f	        (~6–7 digits precision)
    'double'  -> 64-bit floating point    -> 0.0d   -> Not JVM-defined -> 3.14159d	    (~15–16 digits precision)

Syntax: 
    -> Boolean : boolean booleanVar;
    -> byte    : byte byteVar;
    -> short   : short shortVar;
    -> int     : int intVar;
    -> long    : long longVar;
    -> float   : float floatVar;
    -> double  : double doubleVar;
