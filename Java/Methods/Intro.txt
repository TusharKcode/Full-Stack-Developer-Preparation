Java Methods are blocks of code that perform a specific task.
    - allows us to reuse code, improving both efficiency and organization
    - All methods in Java must belong to a class
    - similar to functions and expose the behavior of objects.
    - Dividing a program into separate methods allows each method to handle a specific task

    Rules: 
        - Method names must start with a verb in lowercase.
        - Multi-word names should follow camelCase format.
        - Method names should be unique within a class unless method overloading is allowed in Java.

    Components: 
        - Modifier: Defines access level (public, private, protected, default)
        - Return Type: Specifies what value the method returns or void if no return
        - Method Name: Name of the method, follows camelCase convention
        - Parameters: Optional inputs passed to the method
        - Method Body: Contains the logic or statements to be executed


    Syntax: returnType methodName(parameters) {
                // method body
                return value; // optional (only if returnType is not void)
            }

    Ex: public class Example
        {
                                         // An example method
            public void printMessage() {
                System.out.println("Hello, Geeks!");
            }
            
            public static void main(String[] args) { 
                                            // Create an instance of the class
                                            // containing the method
                Geeks obj = new Geeks();   
                                            // Calling the method
                obj.printMessage(); 
            }
        }

"Call Stack"
    -> When a method is called, Java uses an internal structure known as the call stack to manage execution,
        variables, and return addresses.
    -> used by the program during runtime to manage method calls and local variables
    -> operates in a Last-In-First-Out (LIFO) manner
    -> last method called is the first one to complete and exit

"Method Execution"
    -> When a method is called:
        - A new stack frame is added to the call stack to store method details
        - The method runs its code.
        - After execution, the stack frame is removed, and control goes back to the calling method.

    => Java automatically manages the call stack using the Java Virtual Machine (JVM).

Types of Methods in Java:
    -> Predefined Method
        - already defined in the Java class libraries
        - standard library method or built-in method

        Ex: Math.random()    // returns random value
            Math.PI     //returns the value of π as a constant. it is a Constant not a Method

    -> User-defined Method
        - method written by the user or programmer
        - modified according to the requirement

        Ex: sayHello         // user define method created above in the article
            Greet() 
            setName()

    -> Abstract methods have no body and must be overridden in a subclass. 
        - called using an object of the subclass

Ways to Create Java Method
-> Instance Method - Access the instance data using the object name. Declared inside a class.
    Ex: // Instance Method
        void method_name() {
            // instance method body
        }

-> Static Method - Access the static data using class name. Declared inside class with static keyword.
    Ex: // Static Method
        static void method_name() {
            // static method body
        }

Method Signature
    - Number of parameters
    - Type of the parameters
    - Order of the parameters
