Character Class, which allows you to match one character from a defined set of characters.

    - Match multiple characters using a single pattern
    - Reduce complex conditions
    - Validate inputs like usernames, phone numbers, and passwords

Syntax: [characters]

Types: 
    -> Simple Character Class
        - matches exactly one character from the given set inside square brackets
        - used when you want to allow multiple specific characters at a single position

    ->  Range Character Class
        - matches one character within a specified range using a hyphen (-)
        - used to validate digits, lowercase letters, or uppercase letters efficiently.

    -> Multiple Ranges in a Character Class
        - allows combining several character ranges in one set
        - useful when validating inputs that can contain letters and digits together.

    -> Negated Character Class
        - used to match any single character except the ones specified inside the brackets
        - identified by the caret (^) placed at the beginning of the character set

    -> Predefined Character Classes
        - \d : Digit [0-9]
        - \D : Non-digit
        - \s : Whitespace (space, tab, newline)
        - \S : Non-whitespace
        - \w : Word character [a-zA-Z0-9_]
        - \W : Non-word character

    -> Quantifiers with Character Classes
        - used to specify how many times a character from a defined set or range should appear
        - for validating repeated characters like digits, letters, or symbols.
        - Quantifiers always apply to the preceding character class
        - [0-9]{3} -> digit class repeated 3 times
        - -? -> optional hyphen using quantifier on a character

        *     - Zero or more times (Allows any number of occurrences of a character class) [0]*[0-9]
        +     - One or more times (Requires at least one occurrence of a character class) [0]+[0-9]
        ?     - Zero or one time (Makes a character class optional) [A-Za-z][A-Za-z]-?[0-9][0-9]
        {m}   - Exactly m times (Matches a character class exactly m times) [0-9]{3}
        {m,}  - At least m times (Matches a character class m or more times) [0-9]{2,}
        {m,n} - At least m and at most n times (Matches a character class between m and n times) [0-9]{2,4}

        Types: 
            1. Greedy Quantifier
                - try to match as much of the input as possible while still allowing the overall pattern to
                    match
                - default behavior in Java Regex
                - Default quantifiers (*, +, {m,n})
                - Can be slower due to backtracking
                
            2. Reluctant Quantifier
                - try to match as little of the input as possible
                - created by appending ? to a quantifier symbol
                - Append ? after the quantifier (*?, +?, {m,n}?)
                - Can be slower due to frequent backtracking
                
            3. Possessive Quantifier
                - match as much as possible and do not backtrack.
                - created by appending + to a quantifier symbol
                - Append + after the quantifier (*+, ++, {m,n}+)
                - Often faster, but may cause match failure
