It represents access control to a file or directory by specifying a path name and permitted actions.
    - used by the Java security framework to enforce read, write, execute, or delete operations.
    - Part of the java.io package and extends the Permission class
    - Supports actions like read, write, execute, and delete

    -> Actions: 
        - read: Grants permission to read the file.
        - write: Grants permission to modify/write to the file.
        - delete: Grants permission to delete the file using File.delete().
        - readlink: Grants permission to read symbolic links.
        - execute: Grants permission to execute the file.

    -> Declaration :    public final class FilePermission extends Permission implements Serializable

    -> Constructor:     FilePermission(String path, String actions)

    -> Methods:
        - equals(Object obj): Used to compare two FilePermission objects for equality, returns true only 
                                when both the file path and the permitted actions are exactly the same
                Syntax: public boolean equals(Object obj)

                Ex: FilePermission fp1 = new FilePermission("GEEKS.txt", "read");
                    FilePermission fp2 = new FilePermission("GEEKS.txt", "read");
                    System.out.println(fp1.equals(fp2)); // Output: true

        - getActions(): Provides a standardized (canonical) string of all actions granted to the permission.
                        actions are returned in a fixed order and separated by commas.
                Syntax: public String getActions()
                
                Ex: FilePermission fp = new FilePermission("GEEKS.txt", "read,write");
                    System.out.println(fp.getActions()); // Output: read,write

        - hashCode(): Generates a hash value that represents the FilePermission object, value is consistent 
                        with equals() & useful when permissions are stored in hash-based collections
                Syntax: public int hashCode()
                
                Ex: FilePermission fp1 = new FilePermission("GEEKS.txt", "read");
                    System.out.println(fp.hashCode()); // Output: some integer hash value

        - implies(Permission arg): current permission fully covers another permission, returns true if the 
                                    current object allows all actions requested by the given permission.
                Syntax: public boolean implies(Permission p)
                
                Ex: FilePermission fp1 = new FilePermission("GEEKS.txt", "read,write");
                    FilePermission fp2 = new FilePermission("GEEKS.txt", "read");
                    System.out.println(fp1.implies(fp2)); // Output: true

        - newPermissionCollection(): Creates a container designed specifically to hold multiple FilePermission objects,
                                        helps manage permissions efficiently within Java’s security framework
                Syntax: public PermissionCollection newPermissionCollection()
                
                Ex: FilePermission fp1 = new FilePermission("GEEKS.txt", "read");
                    FilePermission fp2 = new FilePermission("GEEKS.txt", "write");
                    PermissionCollection pc = fp1.newPermissionCollection();
                    pc.add(fp1);
                    pc.add(fp2);
                    System.out.println(pc.elements().hasMoreElements()); // Output: true
