The Dequeue interface is part of the java.util package and extends the Queue interface.
    - stands for Double-Ended Queue
    - represents a linear collection that allows insertion, removal, and retrieval of elements from both ends.
    - Allows insertion and deletion from both front and rear
    - Can be used as both stack (LIFO) and queue (FIFO)
    - Common implementations are ArrayDequeue and LinkedList

=> Declaration: public interface Dequeue<E> extends Queue<E>

=> Common implementations:
    -> LinkedList: Doubly-linked list; supports all dequeue operations; allows nulls.
    -> ArrayDequeue: resizable array implementation; fast for insertion/removal at both ends; not thread-safe.
    -> ConcurrentLinkedQueue: Thread-safe dequeue based on linked nodes; suitable for concurrent use.

=> Operations:
    -> Adding Elements
        - To add elements in a Dequeue, you can use add() , addFirst(), or addLast(), allowing insertion at 
            either end

    -> Removing Elements
        - removed from both ends using removeFirst(), removeLast(), pop(), or poll() 
        - variants; pop() throws an exception if empty, while poll() is safe. 

    -> Iterating Elements
        - a Dequeue can be iterated from both directions
        - iterator method of the Dequeue interface provides us two ways to iterate. One from the first and 
            the other from the back.
