# Full Stack Development Preparation

This repository is a personal learning archive for full-stack development. It contains notes, examples, and practice programs covering Java, databases, frontend basics, Python, networking, and computer fundamentals.

## Overview

The workspace is organized by topic so it can be used as a reference while learning and practicing core concepts.

## Java

The Java section contains a wide range of practice programs and concept notes. It includes:

- Basics and syntax practice under Java/Basics/Practice
- Array and matrix exercises under Java/Arrays/Practice
- Collection framework examples in Java/Collections/
- OOP practice in Java/OOPS/Practice
- Exception handling, file handling, generics, interfaces, and regex examples
- Stream and functional programming topics in Java/JavaFeatures/
- JDBC connection examples in Java/JDBC/DBConnections/
- Multithreading and networking examples in Java/MultiThreading/ and Java/Networking/
- Common coding exercises in Java/Practice/

Examples include programs such as Palindrome, Factorial, MatrixAddition, ReverseString, SecondLargestNum, and VowelsCounter.

## Database and SQL

The database section focuses on relational databases, SQL, PostgreSQL, NoSQL, and MongoDB.

### SQL

The SQL notes are organized into topics such as:

- Basics: data types, commands, operators, comments
- Queries: SELECT, INSERT, UPDATE, DELETE, dynamic queries
- Clauses: WHERE, GROUP BY, HAVING, ORDER BY, LIMIT, DISTINCT
- Joins: inner, outer, left, right, self, cross, recursive joins
- Constraints: primary key, foreign key, unique, check, default, not null
- Functions: string, numeric, date, conversion, statistical, JSON
- Indexes and views
- Subqueries and advanced design concepts

### Relational Databases and PostgreSQL

The Relational-DBs section includes notes on:

- SQL and PostgreSQL fundamentals
- Relationships and normalization
- Primary and foreign keys
- Joins and view creation
- SQL injection basics

### NoSQL and MongoDB

The MongoDB and NoSQL content covers:

- MongoDB basics and document structure
- CRUD operations
- Query operations and array/nested field handling
- Aggregation pipelines
- Indexing and tools such as MongoDB Shell and Compass

## How to Use This Repository

1. Read the .txt notes directly in VS Code or any text editor.
2. Open Java source files and practice them locally.
3. Use the SQL notes as reference material while learning database concepts.
4. Compile and run Java programs from the root folder.

Example:

```bash
javac Java/Practice/Palindrome.java
java -cp Java/Practice Palindrome
```
