The 'grid-column' and 'grid-row' properties let you specify the horizontal and vertical placement 
    of grid items within a grid layout.

These grid lines are the boundaries that separate rows and columns you have already defined using 
    the [grid-template-rows] and [grid-template-columns] properties.

-> <start-line> is the grid line where the item starts.
-> <end-line> is the grid line where the item ends.
    => Both are 1-indexed, that is, you start counting them from 1, not 0.
Syntax: 
        grid-row: <start-line> / <end-line>;
        grid-column: <start-line> / <end-line>;

Example:
        .grid {
            display: grid;
            grid-template-columns: repeat(4, 1fr); /* 4 equal columns */
            grid-template-rows: repeat(3, 100px); /* 3 equal rows */
            gap: 10px;
        }

        .grid > div {
            display: grid;
            place-items: center;
            background: crimson;
            color: white;
            font-size: 4rem;
        }
        <div class="grid">
            <div class="item1">1</div>
            <div class="item2">2</div>
            <div class="item3">3</div>
            <div class="item4">4</div>
            <div class="item5">5</div>
            <div class="item6">6</div>
            <div class="item7">7</div>
            <div class="item8">8</div>
            <div class="item9">9</div>
            <div class="item10">10</div>
            <div class="item11">11</div>
            <div class="item12">12</div>
        </div>

=> You can target these lines to start using the [grid-row] and [grid-column] properties to determine 
    where you should place an item.
=> You can also use the span keyword to tell the grid item which row and column to span across.

Example: 
        .grid {
            display: grid;
            grid-template-columns: repeat(4, 1fr); /* 4 equal columns */
            grid-template-rows: repeat(3, 100px); /* 3 equal rows */
            gap: 10px;
        }

        .grid > div {
            display: grid;
            place-items: center;
            background: crimson;
            color: white;
            font-size: 4rem;
        }

        .item1 {
            grid-column: 1 / 3;
            grid-row: 1 / 3;

            grid-column: 1 / span 2;
            grid-row: 1 / span 2;
        }
        <div class="grid">
            <div class="item1">1</div>
            <div class="item2">2</div>
            <div class="item3">3</div>
            <div class="item4">4</div>
            <div class="item5">5</div>
            <div class="item6">6</div>
            <div class="item7">7</div>
            <div class="item8">8</div>
            <div class="item9">9</div>
            <div class="item10">10</div>
            <div class="item11">11</div>
            <div class="item12">12</div>
        </div>


Example:
.grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr); /* 4 equal columns */
  grid-template-rows: repeat(4, 100px); /* 4 equal rows */
  gap: 10px;
}

.grid > div {
  display: grid;
  place-items: center;
  background: crimson;
  color: white;
  font-size: 4rem;
}

.item1 {
  grid-column: 1 / span 2;
}

.item4 {
  grid-column: 1 / span 3;
}

.item6 {
  grid-column: 1 / span 2;
}

.item7 {
  grid-column: 3 / span 2;
}

<div class="grid">
  <div class="item1">1</div>
  <div class="item2">2</div>
  <div class="item3">3</div>
  <div class="item4">4</div>
  <div class="item5">5</div>
  <div class="item6">6</div>
  <div class="item7">7</div>
</div>
