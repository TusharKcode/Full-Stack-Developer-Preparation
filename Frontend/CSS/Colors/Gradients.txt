Gradients in CSS allow you to create smooth transitions between two or more specified colors. 
    They are often used to add depth, texture, and visual interest to web designs without the need 
    for image files.

=> Linear gradients create a gradual blend between colors along a straight line. You can control the 
    direction of this line and the colors used.
    - You can use other directions like to left, to top, to bottom, or even specify angles like 45deg.

    Example: 
            <div class="linear-gradient"></div>
            .linear-gradient {
                background: linear-gradient(to right, red, blue);
                height: 40vh;
            }

            -> You can also use multiple color stops in a linear gradient:

                <div class="multi-color-gradient"></div>
                .multi-color-gradient {
                    background: linear-gradient(to right, red, yellow, blue);
                    height: 40vh;
                }

=> Radial gradients, create circular or elliptical gradients that radiate from a central point.

    Example:
            <div class="radial-gradient"></div>
            .radial-gradient {
                background: radial-gradient(circle, red, blue);
                height: 40vh;
            }

            -> You can also specify the shape and size of radial gradients:
                <div class="custom-radial-gradient"></div>
                .custom-radial-gradient {
                    background: radial-gradient(ellipse at top left, red, blue);
                    height: 40vh;
                }


=> Both linear and radial gradients allow you to specify color stops at precise positions.

    Example:
            .precise-gradient {
                background: linear-gradient(to right, red 20%, yellow 40%, blue 80%);
                height: 40vh;
            }
