The "attribute selector" in CSS is a powerful tool that allows you to target HTML elements based on 
    their attributes.
    - You can apply styles to elements that have specific attributes or even certain values for 
        those attributes.

Example:
        a {
            display: block;
        }

        a[href] {
            color: blue;
            text-decoration: underline;
        }
        <a href="https://example.com">Example link with an href attribute</a>
        <a>Example link without an href attribute</a>

Suppose you want to target only the links that have a title attribute.
The title attribute often provides additional information about the link, and you might want to 
    style these links differently to indicate that they have extra information available.

Example: 
        a[title] {
            font-weight: bold;
            text-decoration: none;
        }
        <a href="https://example.com" title="Example link with a title attribute">Example link with a title attribute</a>

You can also combine attribute selectors to get even more precise.
        a[href][title] {
            display:block;
            color: green;
        }
        <a href="https://example.com" title="Example link with a title attribute">Example link with a title attribute</a>

Another example for an attribute selector is to match a single value within a space-separated list 
    of values in an attribute.
        a[class~="primary"] {
            color: red;
            font-weight: bold;
        }
        <a href="https://example.com" class="btn primary large">Visit Example Site</a>

The [attr~=value] syntax is used here to target all anchor elements where the class attribute 
    contains the word "primary".

If you need to target an element where the attribute value is prefixed by a specific value, then 
    you can use the [attr^=value] syntax.
Example:    
    a[href^="https://"] {
        color: green;
        text-decoration: underline;
    }
    <a href="https://example.com" class="btn primary large">Visit Example Site</a>

To target elements where the attribute value ends with a specific value, you can use the 
    [attr$=value] syntax.
Example:
            a[href$=".com"] {
                color: darkgreen;
                text-decoration: underline dotted;
            }
            <a href="https://example.com">Visit Example Site</a>

When building multilingual websites or handling custom data attributes, you often need to style 
    elements based on the language they contain or specific data values.
    - The lang and data-lang attributes are commonly used for these purposes.
    => The lang attribute is used in HTML to specify the language of the content within an element.

Example: 
        p[lang="en"] {
            font-style: italic;
        }
        <p lang="en">This is an English paragraph.</p>
        <p lang="fr">Ceci est un paragraphe en français.</p>

You can use the attribute selector to target elements with a data-lang attribute.
    Custom data attributes like data-lang are commonly used to store additional information in 
        elements, such as specifying the language used within a specific section of text.
Example: 
        p[data-lang="fr"] {
        color: blue;
        }
        <p data-lang="fr">Ceci est un paragraphe en français.</p>
        <p data-lang="en">This is a paragraph in English.</p>

When working with ordered lists in HTML, the type attribute allows you to specify the style of 
    numbering used, such as numerical, alphabetical, or Roman numerals.
- The type attribute can be set on an ol (ordered list) element to control the numbering format:
    -> 1 for numerical lists (such as 1, 2, 3, ...),
    -> A for uppercase alphabetical lists (such as A, B, C, ...),
    -> a for lowercase alphabetical lists (such as a, b, c, ...),
    -> I for uppercase Roman numerals (such as I, II, III, ...),
    -> i for lowercase Roman numerals (such as i, ii, iii, ...).

Example: 
            ol[type="A"] {
                color: purple;
                font-weight: bold;
            }
            <ol type="A">
                <li>Item 1</li>
                <li>Item 2</li>
            </ol>
