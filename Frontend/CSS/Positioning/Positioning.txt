=> In CSS, positioning allows us to control how elements are laid out on a page.
    By default, elements are statically positioned. 
    This means they follow the normal flow of the document, one after another, from top to bottom, 
        left to right.
"Static positioning"
- It is the default for all elements and doesn't need any special declaration in CSS.

"Relative Positioning"
- It allows an element to be shifted from its normal position without disrupting the flow of the 
    document. 
    
"Absolute Positioning"
- It allows you to take an element out of the normal document flow, making it behave independently 
    from other elements.
- This makes it useful for creating floating UI features such as modals, tooltips, or dropdown menus,
    which can overlap other elements on the page.
- The element overlaps other elements and is placed in its own layer.
- You can move the absolutely positioned element around using the top, bottom, left, and right 
    properties.

"Fixed and Sticky Positioning"
- Each offering distinct behaviors compared to absolute positioning.
- When an element is positioned with position: fixed, it is removed from the normal document flow 
    and placed relative to the viewport, meaning it stays in the same position even when the user 
    scrolls.
    Ex: headers or navigation bars
- position: sticky behaves as a hybrid between relative and fixed positioning.
    Elements like sticky navigation bars, which only become fixed once the user scrolls to a certain
    position.
