With the calc() function, you can perform calculations directly within your stylesheets to 
    determine property values dynamically.

    This means that you can create flexible and responsive user interfaces by calculating 
        dimensions based on the viewport size or other elements.

    A function is a block of code that performs a specific task. Some functions are already 
        defined in CSS, so you can use them directly and pass any necessary values to them to 
        customize how their tasks will be performed.

    -> It will only take one argument. You pass something called an expression as an argument.
        An expression is a combination of values and operators that produces a result.

        Syntax: calc(expression)

        The expression is evaluated to calculate the final result.
        "Evaluated" just means that the values and operators are converted into a single value behind 
            the scenes. 
            The result is assigned to the CSS property where the calculation is being made.
        
        -> You can perform calculations on values that represent length, angle, time, percentages, 
            numbers, and colors. 
            You can also combine different units like pixels, percentages, and ems.
        
        With numbers, all the values in the expression, also called the operands, must have their 
            corresponding units, like px, em, and percentage (%).
        You can use the addition (+), subtraction (-), multiplication (*), and division (/) operators 
            in the expression.

        You can also nest calc() function calls if you need to perform calculations and use those 
            results in other calculations.

            Not Valid = calc(100% - 0)
            Valid = calc(100% - 0px)

        -> If you use the multiplication or division operators, one of the operands has to be unitless. 
            For the division operator, specifically the right operand has to be unitless. 

            Example: calc(5 * 50px)
                     calc(5px * 50)
                     calc(50% / 5)

    Example: 
    div {
        color: white;
        background-color: #1b1b32;
        width: calc(50% - 20px );
    }
    <div>Hello, World!</div>
