Margin and padding are essential properties in CSS for creating well-structured, readable, and 
    visually appealing web pages.

=> Margins control the space outside an element, helping to separate it from other elements and 
    define the layout structure.
    - Margin which applies to outside the border.
    - The four different margin properties are margin-top, margin-right, margin-bottom and 
        margin-left.
    - Another way to use the margin property is with shorthand notation. You can specify one, two, 
        three, or four values at once.
    - The first value applies to the "top and bottom", while the second value applies to the "left and 
        right" sides of the element.
    - If three values are provided, the first value applies to the top margin, the second value to 
        the left and right margin, and the third value to the bottom margin.

=> Padding controls the space inside an element, improving content readability and aesthetic appeal.
    - Padding is applied to the content which is inside the border.
    - The padding property is used to apply space inside the element, between the content and its 
        border.
    - The four padding properties are padding-top, padding-right, padding-bottom and padding-left.
    - Example: This sets the padding to 10px for the top, 20px for the right, 30px for the bottom, 
                and 40px for the left.
    - You can also choose to use the shorthand for the padding property.

Example: 
        <span>Paragraph one</span>
        <p>Paragraph two</p>
        <span>Paragraph three</span>
    p {
        margin-top: 40px;
        margin-right: 40px;
        margin-bottom: 40px;
        margin-left: 40px;
        border: 2px solid black;
    }

    p {
        margin: 10px;
    }

    p {
        margin: 20px 20px 20px 20px;
    }

    p {
        padding-top: 10px;
        padding-right: 20px;
        padding-bottom: 30px;
        padding-left: 40px;
        border: 2px solid black;
    }

    p {
        padding: 10px 20px 30px 40px;
        border: 2px solid black;
    }
