CSS Rule:

=> A CSS rule is made up of two main parts: a selector and a declaration block.
=> A type selector targets all paragraph elements on the page.

    selector {
    property: value;
    }
-> A selector is a pattern used in CSS to identify and target specific HTML elements for styling.
    - Examples of selectors include type selectors, class selectors, and ID selectors.
    - A declaration block applies a set of styles for a given selector, or selectors.
    - Each declaration consists of a property and a value.
    - In this selector list, there is an "id" selector targeting the HTML element with the id value 
        of 'title'. All "id" selectors must start with a hash [#] symbol.
    - Then there is a comma followed by a "class" selector that targets all HTML elements with the 
        class value of subheading. All "class" selectors must start with a dot [.]

    Example: 
    <h1 id="title">Example heading</h1>
    <h2 class="subheading">Example subheading</h2>
    <p>This paragraph is not affected by the selector.</p>
        #title,
        .subheading, p {
            color: navy;
        }
