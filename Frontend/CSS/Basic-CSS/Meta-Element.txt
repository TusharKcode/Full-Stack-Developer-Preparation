Meta Viewport Element

    Syntax: <meta name="viewport" content="width=device-width, initial-scale=1.0, user-scalable=no">

- A crucial component in responsive web design.
- It's a special HTML meta element that gives the browser instructions on how to control the page's 
    dimensions and scaling on different devices, particularly on mobile phones and tablets.
- Placed in the head section of HTML document.
- The [width=device-width] part tells the browser to set the width of the page to match the screen 
    width of the device. This is essential for creating responsive layouts that adapt to different 
    screen sizes.
- The [initial-scale=1.0] sets the initial zoom level when the page is first loaded. A value of 1.0 
    means that the page is displayed at 100% zoom, without any scaling.

- By using this, ensuring that web pages are displayed properly on mobile devices.
- The meta viewport element also allows you to control whether users can zoom in and out of your 
    web pages.
    Possible to disable zooming with the [user-scalable=no] attribute. Many users rely on the 
        ability to zoom for better readability, especially those with visual impairments.
