CSS, which stands for Cascading Style Sheets, is a crucial component of modern web development.
In simpler terms, if HTML is the structure of a web page, CSS is what makes it look good.

With CSS, you can control the layout, colors, fonts, and overall visual appearance of web pages 
    without altering the HTML structure.

CSS works by selecting HTML elements and applying styles to them.

CSS allows you to adjust layouts, font sizes, and other visual elements based on the screen size of
    the device viewing the website.

=> Important feature of CSS is its cascading nature, which is where the "cascading" in its name 
    comes from.
    This means that styles can be inherited and overridden, allowing for a hierarchical structure
        of styling.

    - CSS also supports the use of external stylesheets.
        This means you can keep all your styling rules in a separate file, which can then be linked 
        to multiple HTML pages.
        It enhances the maintainability of websites, especially larger ones.

What Are Some Default Browser Styles Applied to HTML?
- These styles are called "default browser styles" or "user-agent styles".

=> These default browser styles provide basic formatting to ensure that HTML elements are 
    displayed in a readable way across all browsers.
    These styles can vary slightly from one browser to another.
    Example:
    - "Headings" (h1 to h6) are one of the most commonly used HTML elements and are styled by default
        to have varying sizes and weights.
    - Another element with default styles is the "hr" element, which creates a horizontal rule often 
        used to visually separate sections of content. Browsers generally apply a simple line style 
        to this element. The horizontal rule appears as a thin line with spacing above and below the 
        text to distinguish between sections of content.
    - "Blockquotes" are used to indicate a section of text that is a quotation from another source. 
        Browsers typically add indentation and sometimes italicize the text.
        The indentation helps set blockquotes apart from the rest of the text, making it clear that 
        this content is quoted from another source.
    - Another element with default styles is the anchor element (<a>), which is styled with a 
        default blue color and underlining to make it recognizable as a link.
    - Browsers add basic formatting to lists, including indentation and bullets or numbers, 
        depending on whether you are using an unordered list (ul) or an ordered list (ol).
        Both of these lists will be slightly indented to the right by default.

Examples: 
        <h1>Heading 1</h1>
        <h2>Heading 2</h2>
        <h3>Heading 3</h3>
        <hr>
        <h4>Heading 4</h4>
        <a href="https://freecodecamp.org/">Visit the freeCodeCamp learn page</a>
        <h5>Heading 5</h5>
        <blockquote>I think, therefore I am. (Rene Descartes)</blockquote>
        <h6>Heading 6</h6>

        <p>Sample Paragraph</p>
        <ol>
            <li>item 1</li>
            <li>item 2</li>
            <li>item 3</li>
        </ol>
        <ul>
            <li>item</li>
            <li>another item</li>
            <li>yet another item</li>
        </ul>
        <p>Ending Paragraph</p>
