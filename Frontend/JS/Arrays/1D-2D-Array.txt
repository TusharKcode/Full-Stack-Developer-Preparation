"One-Dimensional" 
- A one-dimensional array, often called an array, is like a single row of boxes.
- Each item in a one-dimensional array is accessed using a single index.
- Suitable for linear data like lists or sequences. 

Example:
        let fruits = ["apple", "banana", "cherry", "date"];
        console.log(fruits[2]); // "cherry"

"Two-Dimensional"
- A two-dimensional array is like a grid of lockers – multiple rows and columns. 
- Essentially an array of arrays.
- Represent data that has a natural grid-like structure, such as a chessboard, a spreadsheet, or pixels in 
    an image.

- To access an element in a two-dimensional array, you need two indices: one for the row and one for 
    the column.
Example:

    => The first index, 0, selects the first row, and the second index, 3, selects the fourth column in 
        that row.
        let chessboard = [
            ["R", "N", "B", "Q", "K", "B", "N", "R"],
            ["P", "P", "P", "P", "P", "P", "P", "P"],
            [" ", " ", " ", " ", " ", " ", " ", " "],
            [" ", " ", " ", " ", " ", " ", " ", " "],
            [" ", " ", " ", " ", " ", " ", " ", " "],
            [" ", " ", " ", " ", " ", " ", " ", " "],
            ["p", "p", "p", "p", "p", "p", "p", "p"],
            ["r", "n", "b", "q", "k", "b", "n", "r"]
        ];

        console.log(chessboard[0][3]); // "Q"
