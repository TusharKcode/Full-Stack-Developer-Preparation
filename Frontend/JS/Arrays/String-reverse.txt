Reversing a string is a common programming task that can be accomplished in JavaScript using a combination of 
    string and array methods.

Steps:
    - Splitting the string into an array of characters. split()
    - Reversing the array.                              reverse()
    - Joining the characters back into a string.        join()

The first step in reversing a string is to convert it into an array of individual characters. 
    - The split() method divides a string into an array of substrings and specifies where each split should 
        happen based on a given separator. 
    - If no separator is provided, the method returns an array containing the original string as a single 
        element. 
    - Examples of common separators include:
            -> An empty string (""), which splits the string into individual characters.
            -> A single space (" "), which splits the string wherever spaces occur.
            -> A dash ("-"), which splits the string at each dash.
    
    Example:
        let str = "hello";
        let charArray = str.split("");
        console.log(charArray); // ["h", "e", "l", "l", "o"]

The second step is reverse() method is an array method that reverses the elements of an array in place.
    - This means it modifies the original array rather than creating a new one.
Example:
        let charArray = ["h", "e", "l", "l", "o"];
        charArray.reverse();
        console.log(charArray); // ["o", "l", "l", "e", "h"]

The final step is to convert the reversed array of characters back into a string. 
    - The join() method creates and returns a new string by concatenating all the elements in an array, 
        separated by a specified separator string.
    - If you want to join the characters without any separator, you can use an empty string as the argument.

Example:
        let reversedArray = ["o", "l", "l", "e", "h"];
        let reversedString = reversedArray.join("");
        console.log(reversedString); // "olleh"
