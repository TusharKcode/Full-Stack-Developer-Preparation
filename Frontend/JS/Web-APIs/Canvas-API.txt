The Canvas API is a powerful tool that lets you manipulate graphics right inside your JavaScript file. 

    - Everything begins with a canvas element in HTML. 
    - It serves as a drawing surface that you can manipulate using the instance methods and properties 
        of the Canvas API.

    - The Canvas API provides everything you need to create amazing visuals, including shapes, text, 
        animations, and even complex games.

    - It has interfaces like HTMLCanvasElement, CanvasRenderingContext2D, CanvasGradient, CanvasPattern, 
        TextMetrics which provide methods and properties you can use to create graphics in 
        your JavaScript file.

Example: 
    // First, you need to create a canvas element in your HTML file:
        <canvas id="my-canvas"></canvas>

    // You can give your canvas a width and height inside the HTML:
        <canvas id="my-canvas" width="400" height="400"></canvas>

    // OR you can use the width and height properties of the HTMLCanvasElement interface:
        const canvas = document.getElementById("my-canvas");
        canvas.width = 400;
        canvas.height = 400;

    // next thing to do is to get access to the drawing context of the canvas with the getContext() methods
        - The most common context is 2d, which allows you to draw in two dimensions
        - With console.log, see the methods and properties of CanvasRenderingContext2D, use to create 
            shapes, colors, lines, and more, along with their default values

        const canvas = document.getElementById("my-canvas");
        const ctx = canvas.getContext('2d');
        console.log(ctx);

    // One of those is the fillStyle property, which you can combine with the fillRect() method to draw
        a rectangle or square.
        - "fillRect" takes 4 number values which represent the x axis, y axis, width, and height
            // Set the background color
                ctx.fillStyle = "crimson";
            // Draw a rectangle
                ctx.fillRect(1, 1, 150, 100);

            // For text: 
                <canvas id="my-text-canvas" width="300" height="70"></canvas>
                <script>
                    const textCanvas = document.getElementById("my-text-canvas");
                    const textCanvasCtx = textCanvas.getContext("2d");
                // Set font family and size
                    textCanvasCtx.font = "30px Arial";
                // Set text color
                    textCanvasCtx.fillStyle = "crimson";
                // Draw the text
                    textCanvasCtx.fillText("Hello HTML Canvas!", 1, 50);
                </script>
