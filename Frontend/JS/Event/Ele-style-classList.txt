The Element.style property is a read-only property that represents the inline style of an element. 
    - The style property can be used to set many CSS properties, such as color, background-color, 
        font-size, font-weight, and so on.
Example: 
        <p id="para">This is a paragraph</p>
        <script src="index.js">
            const paraEl = document.getElementById("para");
            paraEl.style.color = "red";
        </script>

=> Another way to manipulate styles is by using the Element.classList property. 
    - It is a read-only property that can be used to add, remove, or toggle classes on an element.
    - You can also add multiple classes to an element by passing them as arguments to the 
        classList.add() method
        Ex: classList.add("class1", "class2", "class3");
    - If you need to remove a class from an element, you can use the classList.remove() method
        Ex: classList.remove("highlight");

Example: 
        <style>
            .highlight {
                background-color: yellow;
            }
        </style>
        <p id="para">This is a paragraph</p>
        <script src="index.js">
            const paraEl = document.getElementById("para");
            paraEl.classList.add("highlight");
        </script>

=> To toggle a class on an element, you can use the classList.toggle() method. 

Example
        <style>
            .menu {
                display: none;
                background-color: lightgray;
                width: 50%;
                padding: 10px;
            }

                .menu.show {
                display: block;
            }
        </style>
        <button id="toggle-btn">Toggle Menu</button>
        <nav id="menu" class="menu">
        <ul>
            <li>Home</li>
            <li>About</li>
            <li>Products</li>
        </ul>
        </nav>
        <script src="index.js">
            const menu = document.getElementById("menu");
            const toggleBtn = document.getElementById("toggle-btn");
            toggleBtn.addEventListener("click", () => menu.classList.toggle("show"));
        </script>
