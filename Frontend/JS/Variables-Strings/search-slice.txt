The [includes()] method is used to check if a string contains a specific substring.
    - If the substring is found within the string, the method returns true otherwise, it returns false.
    - Case-sensitive.
    - Use to check for a substring starting at a specific index in the string by providing a 
        second parameter.
Syntax:     string.includes(searchValue);
Example:    
        let phrase = "JavaScript is awesome!";
        let result = phrase.includes("awesome");
        console.log(result);  // true

        let text = "Hello, JavaScript world!";
        let result = text.includes("JavaScript", 7);
        console.log(result);  // true

The [slice()] method allows you to extract a portion of a string and returns a new string, without 
    modifying the original string.
    - Two Parameters: the starting index and the optional ending index.
    - 'startIndex' is the position where the extraction starts.
    - 'endIndex' is where the extraction ends.
    - You can also use negative numbers as indexes. It counts backward from the end of the string.
Syntax: string.slice(startIndex, endIndex);
Example: 
        let message = "Hello, world!";
        let greeting = message.slice(0, 5);
        console.log(greeting);  // Hello

        let message = "JavaScript is fun!";
        let lastWord = message.slice(-4);
        console.log(lastWord);  // fun!

        let message = "I love JavaScript!"; 
        let language = message.slice(7, 17);    // middle of the string
        console.log(language);  // JavaScript
