"Arithmetic Operator"
- Basic arithmetic operations on numbers, such as addition, subtraction, multiplication, and division.
- Includes operators for more complex arithmetic operations, such as remainder and exponentiation.

=> The addition operator is a plus sign (+). The addition operator allows you to find the total of 
    two or more numbers.

Example: 
        const num1 = 10;
        const num3 = 15;
        const result1 = num1 + num2;
        const result3 = num2 + num1 + num3;
        console.log(result1); // 15
        console.log(result3); // 30

=> The subtraction operator is a minus sign (-). It allows you to find the difference between 
    two numbers. 
Example: 
        const num1 = 10;
        const num2 = 5;
        const result = num1 - num2;
        console.log(result); // 5

=> The multiplication operator is represented by an asterisk (*) and is used to find the product of 
    two or more numbers.
Example: 
        const num1 = 10;
        const num2 = 5;
        const num3 = 15;

        const result1 = num1 * num2;
        const result2 = num2 * num1;
        const result3 = num2 * num1 * num3;

        console.log(result1); // 50
        console.log(result2); // 50
        console.log(result3); // 750

=> The division operator is a slash (/), which differs from the division symbol used in traditional 
    math (÷). 
    If you try to divide by zero, JavaScript will return Infinity.
Example: 
        const num1 = 10;
        const num2 = 5;
        const num3 = 15;

        const result1 = num1 / num2;
        const result2 = num2 / num1;
        const result3 = num2 / num1 / num3;

        console.log(result1); // 2
        console.log(result2); // 0.5
        console.log(result3); // 0.03333333333333333

=> The remainder operator, represented by a percentage sign (%), returns the remainder of a division. 
Example: 
        const num1 = 10;
        const num2 = 3;
        const remainder = num1 % num2;
        console.log(remainder); // 1

=> The exponentiation operator, represented by a double asterisk (**), raises one number to the power
    of another.
Example:
        const num1 = 2;
        const num2 = 3;
        const exponent = num1 ** num2;
        console.log(exponent); // 8

What Happens When You Try to Do Calculations with Numbers and Strings?
=> In JavaScript, the + operator does double duty. It handles both addition and string concatenation,
    which is a way to join two strings together.
=> When you use (+) with a number and a string, JavaScript decides to treat them both as strings and 
    joins them together.
Example: 
    const result = 5 + '10';
    console.log(result); // 510
    console.log(typeof result); // string

    const result = '10' + 5;
    console.log(result); // 105
    console.log(typeof result); // string

"Type Cercion"
=> JavaScript sees a string in '10' and a number in 5, so it converts the number to a string and 
    concatenates them. This is known as type coercion. 
=> When a value from one data type is converted into another.

Example:
        const subtractionResult = '10' - 5;
        console.log(subtractionResult); // 5
        console.log(typeof subtractionResult); // number

        const multiplicationResult = '10' * 2;
        console.log(multiplicationResult); // 20
        console.log(typeof multiplicationResult); // number

        const divisionResult = '20' / 2;
        console.log(divisionResult); // 10
        console.log(typeof divisionResult); // number

What if the string doesn't look like a number? 
Ex:
    const subtractionResult = 'abc' - 5;
    console.log(subtractionResult); // NaN
    console.log(typeof subtractionResult); // number

    const multiplicationResult = 'abc' * 2;
    console.log(multiplicationResult); // NaN
    console.log(typeof multiplicationResult); // number

    const divisionResult = 'abc' / 2;
    console.log(divisionResult); // NaN
    console.log(typeof divisionResult); // number

What if you perform arithmetic operations with a boolean (true or false)? 
=> true becomes 1, and false becomes 0.
Ex:
    const result1 = true + 1;
    console.log(result1); // 2
    console.log(typeof result1); // number

    const result2 = false + 1;
    console.log(result2); // 1
    console.log(typeof result2); // number

    const result3 = 'Hello' + true;
    console.log(result3); // "Hellotrue"
    console.log(typeof result3); // string

For null and undefined, JavaScript treats null as 0 and undefined as NaN in mathematical operations:
Ex: 
    const result1 = null + 5;
    console.log(result1); // 5
    console.log(typeof result1); // number

    const result2 = undefined + 5;
    console.log(result2); // NaN
    console.log(typeof result2); // number

"Assignment Operators"
- All arithmetic operators have a compound assignment form.
- Compound assignment operators provide a concise shorthand for an operation on a variable followed 
    by storing the result in that same variable.

- They combine the operation and assignment into a shorter form like x += y, which is equivalent to 
    writing x = x + y.

        Example: 
                let num = 5;
                num += 2;
                console.log(num); // 7

=> The [+=] operator lets you add a value to an existing variable. It is known as the addition 
    assignment operator. 
=> The subtraction assignment operator denoted by [-=].
=> The multiplication assignment operator is represented by [*=].
=> The division assignment operator denoted by [/=].
        Example:
                let total = 10;
                total += 5;
                console.log(total); // 15
                
                let score = 20;
                score -= 7;
                console.log(score); // 13

                let points = 5;
                points *= 3;
                console.log(points); // 15

                let balance = 100;
                balance /= 4;
                console.log(balance); // 25

More,
=> Remainder assignment operator (%=), which divides a variable by the specified number and assigns 
    the remainder to the variable.
=> Exponent assignment operator (**=), which raises a variable to the power of the specified number 
    and reassigns the result to the variable.
=> Bitwise AND assignment operator (&=), which performs a bitwise AND operation with the specified 
    number and reassigns the result to the variable.
=> Bitwise OR assignment operator (|=), which performs a bitwise OR operation with the specified 
    number and reassigns the result to the variable.

"Comparison Operators"
- Allow you to compare two values and return a true or false result.
=> The greater than operator, represented by a right-angle bracket (>), checks if the value on the 
    left is greater than the one on the right.
=> The lesser than operator, represented by a left-angle bracket (<) works similarly to >, but in 
    reverse.
=> The greater than or equal operator, represented by a right-angle bracket and the equals sign (>=),
    checks if the value on the left is either greater than or equal to the one on the right.
=> The less than or equal operator, represented by a left-angle bracket and the equals sign (<=) 
    checks if the value on the left is smaller than or equal to the one on the right.
Example:
        let a = 6;
        let b = 9;
        console.log(a > b); // false
        console.log(a < b); // true

        let a = 6;
        let b = 9;
        let c = 6;
        console.log(a >= b); // false
        console.log(b >= a); // true
        console.log(a >= c); // true
        console.log(a <= b); // true
        console.log(b <= a); // false   
        console.log(a <= c); // true
