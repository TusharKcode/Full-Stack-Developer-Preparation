Operator precedence determines the order in which operations are evaluated in an expression.
    Operators with higher precedence are evaluated before those with lower precedence.

Example: 
        const result = 2 + 3 * 4;
        console.log(result); // 14

You may want certain parts of your expression to run first, regardless of precedence rules.
    You can use parentheses, ().

Example: 
        const result = (2 + 3) * 4;
        console.log(result); // 20

The division operator has more precedence than addition or subtraction too.
Example: 
        const result = 2 + 6 / 3;
        console.log(result); // 4

Associativity is what tells JavaScript whether to evaluate operators from left to right or right to 
    left. Like addition and multiplication, associativity is left to right.
Example: 
        const result = 10 - 2 + 3;
        console.log(result); // 11
Some operators, like assignment (=), are right-to-left associative.
Example:
        let a, b;
        a = b = 5;
        console.log(a); // 5
        console.log(b); // 5
        console.log(a + b); // 10
The exponent operator is also right-to-left associative.
Example:
        const result = 2 ** 3 ** 2;
        console.log(result); // 512

"Increment and Decrement Operators"
- The increment and decrement operators are represented by ++ and --.
- Both allow you to adjust the value of a variable by 1.
- You can simply use x++ to add 1, or x-- to subtract 1.
- Two forms, prefix and postfix, For the increment operator, prefix is ++x and postfix is x++.

=> Prefix (++x) increases the value of the variable first, then returns a new value.
=> Postfix (x++) returns the current value of the variable first, then increases it.

        Example:
                let x = 5;
                console.log(++x); // 6
                console.log(x); // 6

                let y = 5;
                console.log(y++); // 5
                console.log(y); // 6

- The decrement operator does the same thing as increment, except it decreases the value by 1.
- Two forms: prefix (--x) decreases the value of the variable first, then returns the new value.
                postfix (x--) returns the current value first, then decreases it.

        Example:
                let x = 5;
                console.log(--x); // 4
                console.log(x); // 4

                let y = 5;
                console.log(y--); // 5
                console.log(y); // 4
