In React, updating arrays in state is quite straightforward, but it can be easy to make a mistake.

In React, state is treated as immutable so it can recognize changes and make the proper updates to the 
    user interface.

-> One of the most common mistakes when updating arrays in a React state is to directly modify the 
    array using methods like push(), pop(), or splice().
    These methods mutate the original array, and React does not allow that.

-> React relies on a new array reference to detect changes, so directly modifying the array can prevent 
    the component from re-rendering as expected.

Example: 
    // using the push() method to add to an array in state and to remove items from the array with the 
        pop() method, which won't work
    // If you click the Add Item button, nothing happens in the user interface.

            import { useState } from "react";

            function ItemsList() {
                const [items, setItems] = useState([
                    { id: 0, name: "Item 1" },
                    { id: 1, name: "Item 2" },
                    { id: 2, name: "Item 3" },
                ]);

                const addItem = () => {
                    const newItem = { id: items.length + 1, name: `Item ${items.length + 1}` };
                    items.push(newItem); // This modifies the original array
                    setItems(items); // React will not detect this change
                };

                const removeItem = () => {
                    items.pop(); // Modifies the original array
                    setItems(items); // React will not detect this change, either
                };

                return (
                    <div>
                        <button onClick={addItem}>Add Item</button>
                        <ul>
                            {items.map((item) => (
                            <li key={item.id}>{item.name}</li>
                            ))}
                        </ul>
                    </div>
                );
            }
            export default ItemsList;

=> To update an array in state, the key is to create a new array, do your operations, and pass that to 
    React, rather than mutate the existing array.

    - Because it's a new array, React will know that the state has been changed, and trigger a re-render.

Example: 
            const addItem = () => {
                const newItem = {
                    id: items.length + 1,
                    name: `Item ${items.length + 1}`,
                };

                // Creates a new array
                setItems((prevItems) => [...prevItems, newItem]);
            };

    // If you want to remove something from the array, you can use the filter() method.
            
            const removeItem = (id) => {
                setItems((prevItems) => prevItems.filter((item) => item.id !== id));
            };

Full code: 
            import { useState } from "react";

            function ItemsList() {
                const [items, setItems] = useState([
                    { id: 0, name: "Item 1" },
                    { id: 1, name: "Item 2" },
                    { id: 2, name: "Item 3" },
                ]);

                const addItem = () => {
                    const newItem = { id: items.length + 1, name: `Item ${items.length + 1}` };
                    setItems((prevItems) => [...prevItems, newItem]); // Creates a new array
                };

                const removeItem = (id) => {
                    setItems((prevItems) => prevItems.filter((item) => item.id !== id)); // Creates a new array
                };

                return (
                    <div>
                        <button onClick={addItem}>Add Item</button>
                        <ul>
                            {items.map((item) => (
                            <li key={item.id}>
                                {item.name}{" "}
                                <button onClick={() => removeItem(item.id)}>Remove</button>
                            </li>
                            ))}
                        </ul>
                    </div>
                );
            }
           export default ItemsList;
