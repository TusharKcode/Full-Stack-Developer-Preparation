State is one of the most important fundamentals of React and other front-end frameworks.
    - It's like the brain of a component, meaning it holds information that can change over time and 
        controls how the components behave and look.

    -> State represents the dynamic data in your React component, like the value from a user input, 
        data fetched from an API, or an item in a to-do list.

        Whenever the state changes, React re-renders the component without reloading the page to reflect those 
            changes in the user interface. 
            This reactivity makes your app interactive.

    -> The 'useState' hook is a function that lets you declare state variables in functional components. 

    -> Introduction of hooks since React 16.8, you can use state in functional components by using 
        the useState hook.

    -> State in a React component is private, and is isolated to each component instance.
        This means that, if you render the same component twice, the state component of one does 
            not affect the other.
        Also, if you'd like to share state between components, then you'd need to lift the state up 
            to a common parent and pass it down as props.

    -> 'Hooks' must be called at the top level of a component, just before the return keyword, 
        to keep the state and effects consistent across renders. 
            This means you can't use state inside loops, conditions, or nested functions.

    -> You can manage multiple pieces of state by calling the useState hook multiple times.

Example: 
        // To use the useState hook, you need to import it from React
                import { useState } from "react";

        // You can also import React itself and get access to the useState hook as a property
                import React from "react";

        // declare a state variable when you import useState
                const [stateVariable, setStateFunction] = useState(initialValue);

        // declare a state variable when you import React
                const [stateVariable, setStateFunction] = React.useState(initialValue);

    -> stateVariable holds the current state value
    -> setStateFunction (the setter function) updates the state variable
    -> initialValue sets the initial state


Example: 
        // Importing the useState hook
        import { useState } from "react";

        function Counter() {
            const initialValue = 0;

            // The state variable and setter function
            const [count, setCount] = useState(initialValue);

            return (
                <div>
                    {/* Display current state value */}
                    <h2>{count}</h2>

                    <button onClick={() => setCount(count - 1)}>Decrement</button>
                    <button onClick={() => setCount(count + 1)}>Increment</button>
                </div>
            );
        }

        export default Counter;
