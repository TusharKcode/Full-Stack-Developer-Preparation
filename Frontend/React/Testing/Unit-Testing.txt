As you design your applications, you will often have a series of small functions responsible for one thing.
    This is known as the "single responsibility principle."

We will see how to create a unit test using the popular Jest testing framework.

=> When it comes to testing JavaScript applications some common testing frameworks include Jest, Mocha, 
    and Vitest.

Example: 
    // create a function that is responsible for returning a newly formatted string
                
                export function getFormattedWord(str) {
                    if (!str) return '';
                    return str.charAt(0).toUpperCase() + str.slice(1);
                }

    // In a separate getFormattedWord.test.js file, we can write some tests to verify that the function is 
        doing what it is supposed to be doing.

        - need to first import the function
        - need to install the Jest package by using [npm i jest]

                import { getFormattedWord } from "./getFormattedWord.js";

    // add a test to check that a word made up of lowercase characters, hello, is properly formatted to 
        Hello, which starts with a capital H

        - The expect function is used to test a value.
        - Jest has a variety of matchers to help you test for truthiness, strings, numbers, and more.

                test('capitalizes the first letter of a word', () => {
                    expect(getFormattedWord('hello')).toBe('Hello');
                });

    // to run your tests is by adding an npm script to your package.json file
                
                "scripts": {
                    "test": "jest"
                },

    // Then just run npm run test in your terminal to run your tests, If your tests pass, you should see 
        something in the terminal
