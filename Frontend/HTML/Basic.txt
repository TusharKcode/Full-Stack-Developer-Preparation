HTML, which stands for Hypertext Markup Language, is a markup language for creating web pages. 
    When you visit a website and see content like paragraphs, headings, links, images, and videos; 
    that's HTML.
    HTML easier to read and help with Search Engine Optimization (SEO) and accessibility.

HTML represents the content and structure of a webpage through the use of elements. 
=> Elements will have an opening tag and a closing tag, referred to as start and end tags.
=> HTML tag names are case-insensitive
=> Some HTML elements do not have a closing tag. These are known as void elements. 
    Void elements cannot have any content and only have a start tag. Ex: <img>

=> There are six heading elements in HTML: h1 through h6.
    - An "<h1></h1>" element is the main heading of a webpage
    - "<h2></h2>" elements represent subheadings.
    - h1 being the most important and h6 the least.

=> When you need to add a paragraph to a webpage, you can use the "<p></p>" element
Example: 
        <h1>Main heading element</h1>
        <p>I am a paragraph element.</p>

=> The 'title' element determines what browsers show in the title bar or tab for the page.

=> The 'main' element is used to represent the main content of the body of an HTML document. 
    Content inside the main element should be unique to the document and should not be repeated 
    in other parts of the document.
Example: 
        <main>
            <h1>Most important content of the document</h1>
            <p>Some more important content...</p>
        </main>

=> The 'figure' element represents self-contained content and will allow you to associate an image 
    with a caption.
    - A figure caption (figcaption) element is used to add a caption to describe the image contained
        within the figure element.
Example: 
        <figure>
            <img src="image.jpg" alt="A description of the image">
            <figcaption>A cute cat</figcaption>
        </figure>

=> To place emphasis on a specific word or phrase, you can use the 'em' element.
=> The 'strong' element is used to indicate that some text is of strong importance or urgent.

=> The 'footer' element is used to define a footer for a document or section. 
    A footer typically contains information about the author of the document, copyright data, 
        links to terms of use, contact information, and more.


=> An "attribute" is a special value used to adjust the behavior for an HTML element.
=> If you wanted to display an image,
        - The 'src' attribute is used to specify the location for that image.
        - The 'alt' attribute is used to provide short, descriptive text for the images.
    Ex: <img src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/running-cats.jpg" 
             alt="Two tabby kittens sleeping together on a couch." />

Accessibility means making sure that everyone, including those with disabilities, can use and 
    understand things like websites, apps, and physical spaces.
=> Inputs are used to collect data from users, and the type attribute specifies the type of input. 
=> The 'checked' attribute is used to specify that the checkbox should be checked by default. It
    does not require a value.

=> If it is present, the checkbox will be checked by default. If the attribute is not present, 
    the checkbox will be unchecked. This is known as a 'boolean' attribute. 
        Ex: such as disabled, readonly, and required. 
        Ex: <input type="text" disabled>
